# 다음무대 — 4일 쓰고 버려지는 무대

2026 크리에이티브X성수 축제에서 찾은 문제를 공공데이터로 확인하고, AI와 예술로 푸는 방법을 프로토타입까지 만든 개인 과제입니다. (한성대 기업연계 AI캡스톤디자인)

- 프로토타입: **https://next-stage-seongsu.vercel.app** (첫 화면의 "시연 순서대로 보기"를 누르면 전체 흐름이 이어집니다)

## 문제

2026년 10월 8일 주제전시 개막일에 에스팩토리를 찾았다. 전시는 4일 동안 열렸다. 대형 현수막, 가벽과 곡면 구조물, 비계 파이프 프레임이 그 4일을 위해 지어졌다가 철거됐다. 성수 팝업은 평균 17.9일마다 바뀌고, 그때마다 같은 자재가 골목으로 나온다. 무엇이 얼마나 나오는지는 아무도 세지 않는다.

## 해법: 다음무대

1. **찍는다** — 운영사가 철거 전 사진을 올리면 AI가 자재 종류·수량·크기를 목록으로 만든다.
2. **잇는다** — 다음 팝업, 작가, 공방의 요청과 짝짓고, 이번 달 철거 물량을 예측해 수거 일정을 짠다.
3. **바꾼다** — 짝을 못 찾은 자재는 성수 작가가 작품으로 만들어 다음 해 주제전시('창조적 변용')에 세운다. 관람객은 작품 QR로 재료가 지나온 길을 '재료의 지도'에서 본다.

## 데이터 분석 재현

```bash
cd analysis
pip install pandas
python download.py            # 서울 열린데이터광장에서 원자료 약 105MB
python store_turnover.py      # results/store_turnover.csv
python living_population.py   # results/chart_lp.json, results/seongsu_living_pop_2025-08_09.csv
```

| 데이터 | 기간 | 결과 |
|---|---|---|
| 서울시 상권분석서비스(점포-행정동) OA-22172 | 2021~2025년 분기 | 등록 점포 교체율((개업+폐업)÷점포 수) 2025년 성수 4개 동 21.5%, 서울 20.1% |
| 행정동 단위 서울 생활인구(내국인) OA-14991 | 2025.8~9월 | 2025 축제 주말 13~18시 성수 4개 동 생활인구가 평소 주말보다 11.0% 많음 (16시 +13,180명). 평일은 차이 1% 이내 |

성수 4개 동은 성수1가1동(11200650)·성수1가2동(11200660)·성수2가1동(11200670)·성수2가3동(11200690)이다. 팝업 평균 운영 기간(17.9일)과 성동구 비중(35.4%)은 스위트스팟 팝업 트렌드 리포트 보도를, 성동구 폐기물 배출량은 뉴스1 보도를 인용했다.

상권분석서비스 CSV는 OpenAPI와 열 순서가 다르다. 처음에 API 순서로 열 이름을 붙여 교체율을 잘못 계산했고, `store_turnover.py`에 머리글 확인을 넣어 바로잡았다.

## 프로토타입

```bash
cd prototype
npm install
npm run dev        # http://localhost:5173
```

`?s=` 뒤에 화면 이름을 붙이면 그 화면이 바로 열린다 (`register`, `result`, `lab`, `match`, `journey`, `dashboard` 등, 목록은 `prototype/README.md`).

실제로 동작하는 것과 시연용을 구분해 둔다.

- 실제: 사진을 9칸으로 나눠 CLIP(`Xenova/clip-vit-base-patch32`, transformers.js)으로 자재를 분류하는 기능. 브라우저에서 직접 계산하고 사진은 밖으로 보내지 않는다. 대시보드의 생활인구 그래프와 점포 교체율도 위 분석 결과다.
- 시연용: 영역 분할·크기 추정 애니메이션(YOLOv8-seg, Depth Anything V2를 가정), 매칭 점수, 철거 물량 예측(LightGBM을 가정), 팝업·작가·작품 데이터.

## 발표자료

```bash
cd deck
npm install
python paint.py paint                          # 물감·붓 자국 이미지
PHOTO_DIR=<사진 폴더> node build_deck.js out.pptx
```

현장 사진은 얼굴이 나와서 저장소에 넣지 않았다. 사진이 없으면 그 자리에 빈 틀이 들어간다.
